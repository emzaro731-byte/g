# iPhone Launcher

A polished iPhone-inspired launcher interface built with Godot 4.x for Android.

## Included

- iPhone-style home screen
- Status bar and widgets
- Search panel
- Control Center-style panel
- App grid with original icons
- Dock
- Home indicator
- Touch-friendly layout
- 1170x2532 design canvas with mobile scaling

## Important

This project recreates the *interaction style* of a modern smartphone launcher using original UI code and placeholder glyphs. It does not include Apple proprietary assets or trademarks.

The current build is a launcher UI prototype. To make it a true Android home-screen launcher that can open installed Android apps, add a native Android intent bridge and register the Android activity as a HOME launcher.

## Run

Open the project in Godot 4.x and run `Main.tscn`.
